# P5 Introducción a la gestión de memoria   

Durante el desarrollo de esta práctica, deberás lograr los siguientes objetivos:

- Entender la aritmética de punteros y la conversión de direcciones a enteros.
- Entender el concepto de alineación y cómo conseguir alinear direcciones en C.
- Comprender la gestión de memoria mediante segmentación que está implementada en Minix 3.1.2a.
